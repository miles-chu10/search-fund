# Twelve-week launch-preparation roadmap

This roadmap prepares a disciplined search decision. It does not authorize fundraising, outreach, financing applications, entity formation, publication, deployment, or an acquisition commitment.

| Week | Outcome | Acceptance gate |
|---:|---|---|
| 1 | Context and boundary locked | Exact chats and live repo linked; summaries are routing hints only |
| 2 | Strategy decision-ready | Required thesis, runway, time, and risk fields decided or explicitly deferred by Miles |
| 3 | Path decision-ready | Traditional, self-funded, and independent-sponsor cases compared without personal invention |
| 4 | Local operating contract proven | Versioned fixtures and schemas validate; no connector, account, or external mutation |
| 5 | Sourcing dry run | Every retained lead has canonical provenance; blocked/conflicting fetches remain visible |
| 6 | Score and workflow reconciliation | Current `screen-v1.0` limits documented; deterministic regression checks pass |
| 7 | Weekly cockpit | Coverage gaps lead; KPI denominators, decisions, and risks are explicit |
| 8 | Diligence room | Privacy-safe pointers and review states work; no gated files enter git |
| 9 | Capital planning | Unknown inputs cannot produce balanced sources/uses, DSCR, approval, or eligibility |
| 10 | Outreach rehearsal only | Synthetic drafts remain unsent with `sentAt: null` and no send path |
| 11 | Flagship validation | Employer demo passes; target-user observations are separated from demand claims |
| 12 | Continue, pivot, or pause | Decision memo records evidence, risks, dependencies, and any later approval gate |

## Phase gates

- **Weeks 1–3 — Decide:** no software default counts as a personal decision.
- **Weeks 4–6 — Prove the contract:** source, model, workflow, and privacy failures must be visible.
- **Weeks 7–10 — Rehearse operations:** keep every contact, send, financing, and confidential-data path disabled.
- **Weeks 11–12 — Validate and decide:** usability evidence may guide iteration; it does not prove demand, revenue, or acquisition performance.
