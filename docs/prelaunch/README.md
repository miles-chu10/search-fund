# Search Readiness OS

**Status:** local, credential-free pre-launch operating system  
**Canonical contract:** [`contracts/prelaunch-os.json`](../../contracts/prelaunch-os.json)  
**As of:** 2026-08-25  
**External mutation:** disabled

This layer extends Main Street Radar; it does not replace the existing sourcing, provenance, or `screen-v1.0` logic. It prepares an evidence-based search decision without implying that capital, a fund, an investor, a lender, a seller, an acquisition target, or professional approval exists.

## What is usable now

- A responsive **Readiness** workspace with an illustrative search hypothesis, ten open user-owned inputs, three bounded path scenarios, a 12-week roadmap, KPI definitions, decision gates, priority risks, diligence folders, draft-only outreach, a source register, and honest portfolio claims.
- Ten source-linked demo leads and the existing deterministic screen, compare, memo, refresh-preview, and capital-preview workflows.
- A versioned, schema-validated pre-launch contract with formulas and fail-closed states.
- Credential-free local operation. Personal finance, contact, tax, bank, investor, and gated seller data are not required or stored.

## What is not implemented or proven

- No live scheduler, persistent CRM, Airtable base, Clay workflow, Google Sheet sync, contact enrichment, outreach, OAuth, or external send.
- No current availability confirmation, proprietary deal flow, SBA eligibility, lender pre-approval, investor interest, capital commitment, fund/entity, client, revenue, acquisition, or product-market fit.
- No secure data room. The diligence index stores only privacy-safe metadata and pointers; confidential files must remain in an approved system outside git.

## Evidence language

- **Sourced:** reported by an identified source; not independently verified.
- **Calculated:** deterministic formula over linked inputs.
- **Inferred:** analyst or model interpretation with rationale.
- **Illustrative assumption:** editable planning input, not a fact or forecast.
- **Unknown:** missing, stale, blocked, conflicting, or user-owned; no favorable default.
- **Recommendation hypothesis:** reversible starting proposal that still requires a named decision gate.

This repository provides planning support, not legal, tax, securities, broker-dealer, accounting, lending, or investment advice. Qualified professionals must review any real structure, compensation, solicitation, financing, diligence conclusion, or transaction.
