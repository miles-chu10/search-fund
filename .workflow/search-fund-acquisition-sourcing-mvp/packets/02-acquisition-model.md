# Packet 02: Acquisition model

## Objective

Define a transparent public-lead screen and scenario-only capital workflow for a first-time operator planning a later manager transition.

## Context

The model prioritizes the next diligence request. It is not a valuation, return forecast, lending decision, or investment recommendation.

## Ownership

The research worker owns only `results/02-acquisition-model.md`. It must not edit application, test, or documentation files and must preserve concurrent changes.

## Do

- Define fixed weights totaling 100, missing/conflict behavior, caps, and thesis gates.
- Define exact sourced/calculated/inference/unknown language.
- Provide self-funded/SBA-style, traditional-search, and independent-sponsor scenario boundaries.
- Cite current primary SBA and SEC program anchors.

## Do Not

- Present legal, tax, lending, securities, or investment guidance as settled.
- Treat public listing claims as normalized or diligence-grade inputs.

## Expected Output

`results/02-acquisition-model.md` with deterministic rules, acceptance fixtures, capital stages, formulas, caveats, and primary citations.

## Verification

Weights total 100; missing inputs never trigger reweighting; caps never increase scores; scenarios remain illustrative until evidence advances them.
