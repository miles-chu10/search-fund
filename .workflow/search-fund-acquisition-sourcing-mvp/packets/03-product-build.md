# Packet 03: Product build

## Objective

Implement the credential-free partner demo, data fixtures, contracts, tests, and documentation.

## Context

The nested repository is the only mutable scope. Research results are read-only integration inputs.

## Ownership

The implementation task owns application code, tests, fixtures, contracts, README/docs, workflow integration artifacts, and the local commit. It must preserve research result files and avoid the parent meta-repository.

## Do

- Implement editable thesis criteria, opportunity ranking, comparison, memo, evidence states, caps, and pipeline actions.
- Implement refresh and capital architecture previews without live mutations.
- Add deterministic scoring, missing-data, provenance, refresh-contract, and rendered smoke tests.
- Keep the demo usable without secrets or network access after install.

## Do Not

- Create external connectors, deploy, publish, contact third parties, solicit capital, or push GitHub.
- Relabel source financial fields or convert unknowns to zero.

## Expected Output

Verified React/TypeScript application, reproducible data and source manifest, docs, tests, and a nested-repository implementation commit.

## Verification

Lint, typecheck, unit tests, source validation, build, desktop/mobile smoke, visual inspection, workflow validation, hygiene scan, and clean Git readback.
